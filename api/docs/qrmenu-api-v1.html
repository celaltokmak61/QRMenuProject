QR Menu REST API

Integrate your digital menu into any application

Version: v1.0
Base URL: https://yourdomain.com/api/v1
Format: JSON
Rate Limit: 150 req/min

🌐 Overview

The QR Menu API gives you programmatic access to your digital menu data. You can read your menu publicly (no authentication required) or manage categories and products with an API key.

ℹ️

Base URL: https://yourdomain.com/api/v1
All requests and responses use JSON format with UTF-8 encoding.

Quick Test

# Verify the API is reachable (no authentication required)
curl https://yourdomain.com/api/v1/
{
  "success": true,
  "name": "QR Menu RESTful API",
  "version": "v1"
}

🔐 Authentication

Most write operations and all management endpoints require an API key. Generate keys from your dashboard under API Settings.

API keys begin with the prefix qrm_ followed by a 48-character random hex string (total 52 characters).

Option 1 — Authorization Header (recommended)

GET /api/v1/categories HTTP/1.1
Host: yourdomain.com
Authorization: Bearer qrm_a1b2c3d4e5f6...
Content-Type: application/json

Option 2 — Query Parameter

GET /api/v1/categories?api_key=qrm_a1b2c3d4e5f6... HTTP/1.1
⚠️

Security: Always use the Authorization header in production. Query parameters may appear in server logs.

Invalid Key Response

{
  "success": false,
  "error": "Invalid API key.",
  "code": 401
}

⏱ Rate Limiting

Each API key is limited to 150 requests per minute. Rate limit counters reset on a rolling 60-second window.

Response Headers

HeaderDescription
X-RateLimit-LimitMaximum requests allowed per minute
X-RateLimit-RemainingRequests remaining in current window
X-RateLimit-ResetUnix timestamp when the window resets

Rate Limit Exceeded (429)

{
  "success": false,
  "error": "Rate limit exceeded. Max 150 requests per minute.",
  "code": 429,
  "retry_after": 34
}
💡

Implement exponential backoff when you receive a 429 response. Use retry_after to know how many seconds to wait.

⚠️ Error Handling

All error responses follow the same structure:

{
  "success": false,
  "error": "Human-readable error message",
  "code": 400
}
CodeMeaningCommon Cause
400Bad RequestMissing or invalid parameters
401UnauthorizedMissing, invalid or disabled API key
404Not FoundResource or endpoint does not exist
429Too Many RequestsRate limit exceeded
500Server ErrorUnexpected internal error

🍽 Public Menu Endpoints

These endpoints are publicly accessible. No API key required. Ideal for embedding menus in websites or mobile apps.

GET /api/v1/menu/{username} Full menu overview — branches, categories and products ▾

Returns the complete menu including all branches, categories and products for the given username.

Path Parameters

ParameterTypeRequiredDescription
username string Required Subdomain/username of the restaurant (e.g. myrestaurant)

Query Parameters

ParameterTypeDefaultDescription
langstringtrLanguage code for translations (e.g. en, de)
branch_idintegerallFilter by a specific branch ID

Example Request

curl https://yourdomain.com/api/v1/menu/myrestaurant \
     -H "Accept: application/json"

Example Response

    "username": "myrestaurant",

      "phone": "+90 212 000 0000",
      "categories": [
        {
          "id": 12,
          "name": "Starters",
          "image": "https://...",
          "products": [...]
        }
      ]

📂 Categories

Manage your menu categories. All endpoints require authentication.

GET /api/v1/categories List all categories ▾

Query Parameters

ParameterTypeDefaultDescription
branch_idintegerallFilter by branch
with_productsboolean0Include products in each category

Example Request

curl https://yourdomain.com/api/v1/categories?with_products=1 \
     -H "Authorization: Bearer qrm_xxxxxxxx"

Example Response

{
  "success": true,
  "categories": [
    {
      "id": 12,
      "name": "Starters",
      "description": "Light bites",
      "image": "https://...",
      "is_active": true,
      "order_number": 1,
      "product_count": 8
    }
  ],
  "meta": { "total": 5 }
}
POST /api/v1/categories Create a new category ▾

Request Body

FieldTypeRequiredDescription
namestringRequiredCategory name (max 255 chars)
descriptionstringOptionalCategory description
order_numberintegerOptionalDisplay order (default: 0)
is_activebooleanOptionalActive state (default: true)

Example Request

curl -X POST https://yourdomain.com/api/v1/categories \
     -H "Authorization: Bearer qrm_xxxxxxxx" \
     -H "Content-Type: application/json" \
     -d '{
       "name": "Desserts",
       "description": "Sweet treats",
       "order_number": 5
     }'

Response 201 Created

{
  "success": true,
  "message": "Category created successfully.",
  "id": 18
}
GET /api/v1/categories/{id} Get a single category ▾

Returns details for a single category. Add ?with_products=1 to include associated products.

curl https://yourdomain.com/api/v1/categories/12?with_products=1 \
     -H "Authorization: Bearer qrm_xxxxxxxx"
PUT /api/v1/categories/{id} Update a category ▾

Partial updates are supported — only include the fields you want to change.

curl -X PUT https://yourdomain.com/api/v1/categories/12 \
     -H "Authorization: Bearer qrm_xxxxxxxx" \
     -H "Content-Type: application/json" \
     -d '{ "name": "Appetizers", "is_active": true }'

Response 200 OK

{
  "success": true,
  "message": "Category updated successfully."
}
DEL /api/v1/categories/{id} Delete a category ▾
⚠️

Deleting a category is permanent. Associated products will remain but will no longer be linked to this category.

curl -X DELETE https://yourdomain.com/api/v1/categories/12 \
     -H "Authorization: Bearer qrm_xxxxxxxx"

Response 200 OK

{ "success": true, "message": "Category deleted." }

POST /api/v1/products Create a new product ▾

Request Body

FieldTypeRequiredDescription
namestringRequiredProduct name
category_idintegerRequiredParent category ID
pricenumberRequiredDefault price
descriptionstringOptionalProduct description
is_availablebooleanOptionalAvailability (default: true)
order_numberintegerOptionalDisplay order (default: 0)
branch_pricesarrayOptionalPer-branch prices: [{branch_id, price}]

Example Request

curl -X POST https://yourdomain.com/api/v1/products \
     -H "Authorization: Bearer qrm_xxxxxxxx" \
     -H "Content-Type: application/json" \
     -d '{
       "name": "Baklava",
       "category_id": 18,
       "price": 85.00,
       "description": "Layers of pastry, honey and nuts",
       "branch_prices": [
         { "branch_id": 1, "price": 85.00 },
         { "branch_id": 2, "price": 90.00 }
       ]
     }'

Response 201 Created

{
  "success": true,
  "message": "Product created successfully.",
  "id": 72
}
GET /api/v1/products/{id} Get a single product ▾

Returns full product details. Add ?with_prices=1 to include branch-specific pricing.

curl https://yourdomain.com/api/v1/products/55?with_prices=1 \
     -H "Authorization: Bearer qrm_xxxxxxxx"
PUT /api/v1/products/{id} Update a product ▾

Partial updates are supported.

curl -X PUT https://yourdomain.com/api/v1/products/55 \
     -H "Authorization: Bearer qrm_xxxxxxxx" \
     -H "Content-Type: application/json" \
     -d '{ "price": 49.90, "is_available": false }'

Response 200 OK

{ "success": true, "message": "Product updated successfully." }
DEL /api/v1/products/{id} Delete a product ▾ 
curl -X DELETE https://yourdomain.com/api/v1/products/55 \
     -H "Authorization: Bearer qrm_xxxxxxxx"

Response 200 OK

{ "success": true, "message": "Product deleted." }

🗄 Data Models

Category Object

{
  "id":           12,          // integer — unique identifier
  "name":         "Starters",  // string  — translated if lang param used
  "description":  "...",       // string|null
  "image":        "https://...",// string|null — full URL
  "order_number": 1,          // integer — display order
  "is_active":    true,       // boolean
  "product_count":8           // integer — only with with_products=1
}

Product Object

{
  "id":           55,
  "name":         "Hummus",
  "description":  "Creamy chickpea dip",
  "price":        45.00,       // float — default/base price
  "currency":     "TRY",
  "image":        "https://...",
  "is_available": true,
  "order_number": 1,
  "category_id":  12,
  "allergens":    ["sesame", "gluten"],
  "branch_prices":[         // only with with_prices=1
    { "branch_id": 1, "price": 45.00 }
  ]
}

Branch Object

{
  "id":          1,
  "name":        "Main Branch",
  "address":     "123 Main St, Istanbul",
  "phone":       "+90 212 000 0000",
  "is_active":   true
}
